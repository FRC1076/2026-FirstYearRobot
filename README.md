
## Using the vertically mounted NavX

Due to the NavX being mounted onto the robot vertically, we need to reconfigure the yaw axis. We do this by holding down the 'CAL' button on the NavX for at least five seconds (after which the orange 'CAL' light should flash for one second before turning off), then pressing the 'RESET' button and waiting 15 seconds for it to calibrate (during which the orange 'CAL' LED should be flashing repeatedly). For this to work, one of the NavX axes must be perpendicular to earth's surface, and the NavX must be held still.
